# 标书制作完整指南

## 一、标书基本概念

### 1.1 商务标、技术标、经济标的定义与区别

**商务标**：
- 主要包括企业资质、业绩、信誉等内容
- 证明企业的综合实力和履约能力
- 包含营业执照、资质证书、获奖证书等

**技术标**：
- 主要包括技术方案、实施计划、人员配置等内容
- 证明企业的技术能力和项目管理水平
- 是评标的核心内容，分值占比最高

**经济标**：
- 主要包括报价、费用明细等内容
- 证明企业的价格竞争力
- 通常采用最低价法或综合评估法

### 1.2 标书的基本结构

```
投标文件
├── 封面
├── 目录
├── 投标函
├── 法定代表人授权书
├── 商务部分
│   ├── 企业简介
│   ├── 资质证书
│   ├── 业绩证明
│   └── 信誉证明
├── 技术部分
│   ├── 项目理解与分析
│   ├── 技术方案
│   ├── 实施计划
│   ├── 人员配置
│   ├── 质量保证
│   └── 售后服务
├── 报价部分
│   ├── 报价说明
│   └── 费用明细
└── 附件
    ├── 营业执照
    ├── 资质证书
    └── 其他证明材料
```

## 二、标书制作流程

### 2.1 前期准备

1. **研读招标文件**
   - 仔细阅读招标文件全文
   - 理解评分标准和要求
   - 提取关键信息和废标条款

2. **组建投标团队**
   - 项目经理：统筹协调
   - 技术人员：编写技术方案
   - 商务人员：准备商务资料
   - 报价人员：编制报价

3. **收集资料**
   - 企业资质证书
   - 项目业绩证明
   - 人员资格证书
   - 技术方案素材

### 2.2 编写阶段

1. **编写技术标**
   - 按评分标准逐项响应
   - 内容充实、有针对性
   - 配合图表说明

2. **编写商务标**
   - 整理企业资质
   - 准备业绩证明
   - 编写企业简介

3. **编制报价**
   - 成本核算
   - 利润分析
   - 竞争策略

### 2.3 审核阶段

1. **内容审核**
   - 是否响应招标要求
   - 数据是否准确
   - 逻辑是否清晰

2. **格式审核**
   - 字体字号统一
   - 段落格式规范
   - 表格图表清晰

3. **合规审核**
   - 是否有废标风险
   - 签字盖章完整
   - 资质证书有效

### 2.4 装订提交

1. **打印装订**
   - 按要求份数打印
   - 正副本区分
   - 装订整齐美观

2. **密封包装**
   - 按要求密封
   - 贴密封条
   - 加盖公章

3. **按时提交**
   - 注意截止时间
   - 提前到达现场
   - 带齐所需材料

## 三、技术标编写要点

### 3.1 项目理解与分析

**编写要点**：
- 表明对项目的深入理解
- 分析项目背景和需求
- 阐述项目的重点和难点

**内容结构**：
1. 项目背景
2. 需求分析
3. 项目目标
4. 重点难点分析

### 3.2 技术方案

**编写要点**：
- 针对性强，符合项目需求
- 技术先进，切实可行
- 逻辑清晰，层次分明

**内容结构**：
1. 总体架构设计
2. 功能模块设计
3. 技术选型说明
4. 系统集成方案
5. 数据安全设计

### 3.3 实施计划

**编写要点**：
- 时间安排合理
- 里程碑明确
- 可操作性强

**内容结构**：
1. 实施策略
2. 进度计划（甘特图）
3. 里程碑节点
4. 交付物清单

### 3.4 人员配置

**编写要点**：
- 人员资质满足要求
- 角色分工明确
- 经验丰富

**内容结构**：
1. 项目组织架构
2. 核心人员介绍
3. 人员资质证书
4. 人员投入计划

### 3.5 质量保证

**编写要点**：
- 体系完善
- 措施具体
- 可追溯

**内容结构**：
1. 质量管理体系
2. 质量控制措施
3. 测试验收方案
4. 质量保证承诺

### 3.6 售后服务

**编写要点**：
- 服务体系完善
- 响应时间明确
- 培训计划详细

**内容结构**：
1. 服务体系
2. 服务内容
3. 响应时间承诺
4. 培训计划

## 四、标书格式规范

### 4.1 页面设置

| 项目 | 标准值 |
|------|--------|
| 纸张 | A4 (210mm × 297mm) |
| 上边距 | 2.54cm |
| 下边距 | 2.54cm |
| 左边距 | 3.17cm |
| 右边距 | 3.17cm |

### 4.2 字体字号

| 元素 | 字体 | 字号 | 行距 |
|------|------|------|------|
| 一级标题 | 黑体 | 三号(16pt) | 固定值28磅 |
| 二级标题 | 黑体 | 小三(15pt) | 固定值28磅 |
| 三级标题 | 黑体 | 四号(14pt) | 固定值28磅 |
| 正文 | 仿宋_GB2312 | 四号(14pt) | 固定值28磅 |
| 表格内容 | 仿宋_GB2312 | 五号(10.5pt) | 单倍行距 |

### 4.3 标题编号

```
一、一级标题
（一）二级标题
1. 三级标题
（1）四级标题
① 五级标题
```

### 4.4 表格规范

- 表头：黑体、加粗、居中
- 内容：仿宋_GB2312、居中
- 边框：四边框线
- 对齐：水平居中、垂直居中

## 五、常见错误与避免

### 5.1 内容错误

| 错误类型 | 正确做法 |
|---------|---------|
| 泛泛而谈 | 针对评分标准逐项响应 |
| 内容空洞 | 具体、详细、有数据支撑 |
| 前后矛盾 | 保持一致性 |
| 复制粘贴 | 根据项目特点定制 |

### 5.2 格式错误

| 错误类型 | 正确做法 |
|---------|---------|
| 字体混乱 | 统一使用规定字体 |
| 段落不齐 | 统一缩进和行距 |
| 标题混乱 | 按层级规范编号 |
| 表格不规范 | 统一格式和对齐 |

### 5.3 废标风险

| 风险点 | 预防措施 |
|--------|---------|
| 资质不满足 | 提前核实招标要求 |
| 签字遗漏 | 逐页检查签字盖章 |
| 超时提交 | 提前准备，预留时间 |
| 密封不当 | 按要求密封包装 |

## 六、投标技巧

### 6.1 评分标准分析

1. **识别高分项**
   - 重点关注分值高的评分项
   - 投入更多篇幅和精力

2. **理解评分规则**
   - 客观分：满足即得分
   - 主观分：越详细越好

3. **针对性编写**
   - 逐条响应评分标准
   - 不遗漏任何评分项

### 6.2 报价策略

1. **成本核算**
   - 人工成本
   - 硬件成本
   - 软件成本
   - 服务成本

2. **利润分析**
   - 合理利润率
   - 市场竞争情况

3. **报价技巧**
   - 不平衡报价
   - 暂定金额处理
   - 优惠条件设置

### 6.3 加分技巧

1. **技术加分**
   - 提供增值服务
   - 技术创新点
   - 成功案例展示

2. **商务加分**
   - 本地化服务
   - 快速响应承诺
   - 延长质保期

## 八、常用模板

### 8.1 投标函模板

```
致：[招标人名称]

1. 我方已仔细研究了[项目名称]招标文件的全部内容，包括澄清答疑文件（如有），我方完全理解并接受招标文件的各项要求。

2. 我方愿意按照招标文件规定的各项要求，以人民币（大写）[金额]元（¥[小写金额]元）的投标总价，承包上述工程的施工、竣工和保修。

3. 如我方中标，我方承诺：
   （1）在收到中标通知书后[天数]天内与贵方签订合同；
   （2）按照招标文件和投标文件的承诺履行合同义务；
   （3）...

投标单位：[单位名称]（盖章）
法定代表人：[姓名]（签字或盖章）
日期：[年月日]
```

```
本授权书声明：[单位名称]的[法定代表人姓名]代表本公司任命[被授权人姓名]为本公司的唯一合法代理人，就[项目名称]的投标活动，以本公司名义处理一切与之有关的事务。

本授权书有效期自[开始日期]至[结束日期]。

投标单位：[单位名称]（盖章）
法定代表人：[姓名]（签字或盖章）
被授权人：[姓名]（签字）
日期：[年月日]
```

## 九、注意事项

1. **仔细阅读招标文件**
   - 不要遗漏任何要求
   - 注意澄清答疑文件

2. **严格按照格式要求**
   - 字体、字号、行距
   - 页边距、装订方式

3. **注意时间节点**
   - 投标截止时间
   - 开标时间
   - 答疑时间

4. **保持沟通**
   - 与招标方保持联系
   - 及时获取澄清信息

5. **团队协作**
   - 分工明确
   - 进度同步
   - 质量把控
